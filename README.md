# 智造未来 · SmartFactory Nexus

基于数字孪生与增强现实的智能柔性制造车间协同管控系统。课程可交互原型，当前版本 **v1.3.0**。系统、需求分析、初步设计、初步技术评估及课程提交版 PPT/PDF 一并交付。

## 给老师的阅读材料

- `deliverables/智造未来-课程提交版.pptx`：26 页可编辑提交版，正文包含问题、设计、操作过程、验证结果与局限，不依赖现场讲解。
- 同名 PDF：用于直接阅读；原 `智造未来-课程答辩.pptx` 是历史版本，不作为本次提交材料。
- [课程对应关系与最终验收](docs/19-课程提交说明与最终验收.md)、[需求分析](docs/01-需求分析.md)、[初步设计](docs/02-初步设计.md)、[系统验证](docs/03-系统验证.md)。

## 启动与构建

Windows 双击 **启动系统.cmd**，会检查 Node、安装缺少的依赖并打开本机浏览器。要求 Node.js **22.12+**（已用 22.23.4 验证）、npm 和支持 WebGL 的浏览器。

```powershell
npm ci
npm run dev -- --port 5174
```

访问 <http://127.0.0.1:5174>。源码和 GitHub 版本归档在私有仓库；原型未公开部署。不要以 file 协议直接打开 HTML。

```powershell
npm run build
npm run preview -- --port 4173
npm test
npm run test:e2e
```

生产预览为 <http://127.0.0.1:4173>。交付包含 `dist/`。浏览器测试使用本机 Chrome 路径，换电脑需修改 `playwright.config.ts` 或安装 Playwright Chromium。

## 实际功能

| 模块 | 已实现行为 |
|---|---|
| 智能驾驶舱 | 统一时钟、产线筛选、加工/质量/入库口径、能耗和事件定位 |
| 数字孪生车间 | 两单元工序驱动取放、门、夹具、刀具、检测/分流；观察内部和历史回放 |
| 生产调度 | 订单增改取消、双配方、能力约束、6秒换型、FCFS/紧急优先、故障未开工毛坯转运 |
| 质量检测 | 3类参数驱动超差、测量/工序/参数因果追溯、隔离报废和同编号去毛刺返工 |
| 设备健康 | 温度/振动曲线、异常注入、维修工单、检查联锁与恢复 |
| 能耗管理 | 标准/高性能/节能模式、积分用电、单位能耗与演示碳排 |
| AR 智能巡检 | 本地 MindAR 图像识别、目标资源、设备叠加、维修步骤及明确三维回退 |
| 数据分析与报告 | 事件检索、时间筛选、CSV/JSON/HTML 导出 |
| 系统设置 | 版本清单检查、四种主题色、深浅色、四档字号、画质/标签/倍速/密度及备份 |

默认三个订单分别绑定两种配方：精密法兰、安装支架板和连接法兰。已有旧存档保留其原产品名称及工艺快照，重置演示才加载新版默认订单。

## 如何复核新增功能

1. 正常生产并选 1× 或 5×；在车间选择 CNC → “观察加工”，查看取料、装夹、切削与送检。20× 适合快速生成业务数据，不适合辨认每个动作。
2. 有已完成工件后选择其编号，使用回放工序、时间滑块和回放速度。回放不改变生产时钟或统计。
3. 新建安装板订单，查看换型等待；单元没有投料时可调整可加工产品。紧急订单只重排未开工队列。
4. 注入 CNC 故障：在制件保留原位；有可用目的缓冲位时，待加工毛坯经 8 秒转运到另一兼容单元。
5. 质量页在投料前应用“装夹偏移 / 补偿偏差 / 漏去毛刺”场景。已有队列保留旧参数；开启人工处置后超差件留待处理。先恢复后续参数，再报废补投。仅毛刺可返工，返工保留原编号和首检。
6. 选择 ASRS 查看库存；满仓会阻塞入库。点击发运释放容量，历史订单完成量保留。
7. 设备健康或 AR 页创建维修工单，完成三项确认后恢复；报告页导出记录。

可通过设置导出完整备份。交付的 `deliverables/示例完整备份-v1.3.json` 使用同样结构，供离线审阅；旧版示例仍保留用于迁移检查。

## AR 使用与验收边界

本地资源为 MindAR 1.2.5 与独立 Three.js 0.151.3；主车间使用 Three.js 0.180，两个渲染生命周期隔离。目标图是 `public/ar-targets/equipment-target.png`，实际编译资源是 `equipment.mind`。

电脑 localhost 可请求摄像头；手机需要 HTTPS 安全上下文。用另一屏幕或打印件显示完整目标，授权后对准。权限拒绝/无摄像头可进入明确标注的普通三维维修演示，其不使用摄像头或图像识别。

实际已验证桌面合成视频流识别目标、叠加模型、关闭后释放媒体轨道。**真实 Android/iOS、光照、遮挡与跟踪精度仍待实测**，没有虚构手机成功率。

## 数据、时间和统计

唯一模拟时钟每 100ms 墙钟推进所选倍速的模拟时间，内部按工序、转运、换型、开工与10秒采样边界切分。种子42产生可重复演示偏移；三维从同一工序状态读取姿态。每件工件保存配方/参数及工序起止区间。

法兰周期49秒，安装板52秒；换型6秒，正常物流14秒，替代路线转运8秒。两单元共享QC，物流任务采用保守的独占资源策略。仓储480件，12个逻辑货格每格按40件聚合显示，没有实际装箱尺寸标定。

加工数在切削结束后增加，订单在合格入库后完成。首检良品率排除重复抽检与返工复测；返工不新增产品。报告综合效率是明确公式的演示指标，未经工业标定；能耗及0.57 kgCO₂/kWh碳因子均为设定假设。

运行中的存档在序列化前合并到每秒一次，暂停立即保存，离开页面刷新最新快照；恢复默认暂停。事件保留最近2000条、设备曲线保留最近180点。默认批次已验证存档低于5MiB；长期大规模历史需服务端或其他存储。

## 验证与已知限制

58项单元、21项浏览器用例和生产构建通过；九页×三种宽度共27个生产布局组合没有横向溢出。完整批次与模式对比见 `deliverables/v1.3-final-validation.json`；测试文件在 `tests/`。

原型未连接PLC、工业协议或生产数据库；没有训练后的视觉/诊断模型，没有切削力、碰撞动力学或真实机床标定。专家、真实用户、工厂现场和手机评估均未开展，提供 [待填评估表](docs/20-后续实测与评估表.md)。
