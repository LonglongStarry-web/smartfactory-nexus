## 状态一致性验证

同一 CNC-01 在健康页注入温度异常后，三维详情为故障，调度显示停机并不再承担任务，统一告警新增。维修恢复后，告警标为解决，事件历史保留，设备根据模拟运行/暂停状态变为运行或待机。驾驶舱运行率与告警数直接计算同一设备数组，不存在第二份状态源。

## 开发中发现并修复的问题

1. 浮点累计边界造成10秒节拍少结算一件：使用微小数值容差，120秒24件测试通过。
2. 三维 HTML 标签在页面卸载时触发 removeChild 异常：改为相机投影加统一 React 覆盖层，最终所有页面切换无 pageerror。
3. AR 缺少 CSS3DRenderer 的 import map：将真实模块本地化并映射，合成图像识别通过。
4. 上游 MindAR 在初始化失败时直接 stop 会访问不存在的 controller：采用防御式资源释放，并在初始化前明确处理摄像头错误。
5. 小字号与 PPT 截图重复等比缩放：生产 UI 所有正文元素至少11px；截图修复为一次等比缩放，逐页复核。

早期失败属于调试记录，不算作最终验收通过。最终结果以交付测试 JSON 为准。

## 视觉审查

三维结构、页面对齐和移动导航均已查看真实截图。UI inspector 仍有四项警告：品牌英文大写、Consolas 回退检测、紧凑信息区11–12px文字较多，以及零数据初始页面的面板留白。保留品牌写法与固定面板框架；IBM Plex Mono 已本地加载，Consolas只是系统回退；信息密度仍有进一步优化空间。没有低于11px的FAIL。截图审查不等于真实用户可读性研究。

## 局限与改进

本系统验证的是交互闭环与规则一致性，不证明真实生产效率提升。无PLC、无真实视觉模型、无物理校准、无服务器与权限体系。排产为并行设备规则抽象。AR目前只有一个图像目标和一种简化设备模型，多设备身份由页面选择绑定。缺少手机实测、持续运行压力测试和真实用户评估。后续优先补齐这些证据，而不是增加装饰性特效。
