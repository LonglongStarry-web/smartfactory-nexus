# 可选交互复核脚本（约7分钟）

老师直接阅读提交版PPT/PDF即可理解，本脚本不作为阅读前提。保留它是为了满足最初任务的可重复演示要求。

| 时间 | 操作与说明 |
|---|---|
| 0:00–0:50 | 说明两加工单元共享QC/仓储；订单只在合格入库时完成。指出所有数据是课程仿真。 |
| 0:50–1:50 | 正常生产选5×，在三维车间选择CNC→观察加工；观察抓取、门、装夹与切削。必要时选1×辨认细节。 |
| 1:50–2:40 | 有完成记录后选择工件回放，跳到钻孔并拖动时间。说明参数快照及回放不改生产。 |
| 2:40–3:40 | 调度查看两配方能力与6秒换型，新增小批紧急安装板订单；说明在制件不被插单替换。 |
| 3:40–4:40 | 质量页解释定位、补偿、毛刺的测量规格；已有记录查看因果链。人工处置与毛刺返工需在投料前配置场景，可提前准备记录，避免等待完整周期。 |
| 4:40–5:50 | 设备健康注入故障、建立工单、完成三项确认后恢复。AR展示真实目标资源及三维回退；没有手机实测时不声称手机识别成功。 |
| 5:50–7:00 | 报告导出CSV/JSON/HTML；说明58项单元、21项浏览器与批次守恒，最后指出PLC、真实工艺、用户/专家及手机验证边界。 |

如需快速准备数据，可先20×运行并暂停，再选择1×/5×观察。不要以20×跳过的动作判断机械路径是否存在，也不要把规则输入造成的超差解释为已经证明现场设备根因。
