## 设计说明

品牌以用户指定工业蓝灰为准，覆盖 UI 技能默认“纯中性黑”建议。保留细线选中、无发光和渐变装饰、扁平容器、统一数值口径。使用带标签导航而非抽到的图标轨，因为用户明确要求八个导航项。字体为 Public Sans 和 IBM Plex Mono，中文采用系统微软雅黑。所有样本产品、订单、设备与功率参数均为课程模拟数据。
