# v1.1.0 更新说明

发布日期：2026-11-10。保留浏览器已有的订单、故障与维修记录，无需清空本地存储。

## 排产时间

原来的“计划 / 预计完成”混用一列，现拆为 **计划开始、完工时间、交付期限**。完工时间明确标注“预计完工”或“实际完工”。取消订单显示取消，设备全部不可用时显示待排产，历史已完成但无时间记录时显示缺失原因。

此前的预计时间只计算剩余整件数量，忽略当前工件加工进度。每推进一秒，预计完成增加一秒，完成一件后又扣除一个节拍，形成约0–10秒的循环。现为：

`预计完工 = 本任务预计开工 + (剩余整件数 - 当前件已加工比例) × 当前模式每件节拍`

只有当前正在同一设备加工的订单抵扣进度，后续排队任务没有此抵扣。例如剩10件、当前件完成30%，标准节拍10秒，剩余时间97秒；再运行1秒后剩96秒，绝对完工时刻保持不变。插单、模式切换、设备故障仍会合理改变预计时间。

同时修复了订单重新分配时加工进度串到新订单的问题，以及未来开工订单提前消耗一秒的问题。完成时保存 `completedAt`，实际完工不会在之后继续变化。编辑表单按打开时的模拟时间计算偏移，保留原有计划与交付期限。

## 指示灯安装

按结构定义安装基准，统一使用底座、支杆、灯体和顶盖。CNC安装在顶盖内，检测站安装在顶部框架，机械臂安装在新增的落地控制箱上，仓库安装在立柱上，AGV增加低位信号灯。设备状态色独立于界面主题色。

## 系统设置

导航新增“系统设置”，版本号同步显示v1.1.0。所有偏好立即生效并保存在本浏览器：

- 深色、浅色、跟随系统。
- 冰川青、远山蓝、森林绿、琥珀金，作用于界面重点与图表主序列。
- 紧凑/舒适表格密度。
- 三维车间标准/低画质及设备标签，与车间工具栏双向同步。
- 减少界面动效，相机直接定位，设备仍按生产状态演示。
- 默认1×/5×/20×，同时应用于当前模拟，重置后沿用。
- 完整工作空间JSON备份（生产状态和设置）。
- 恢复默认设置需确认，仅恢复偏好，保留生产与维护记录。

## 版本检查的实际范围

点击“检查更新”会真实请求当前部署的 `/version.json`，禁用缓存，校验版本号和清单格式，再比较当前包版本。界面区分正在检查、清单中已最新、发现较新版本、网络/格式错误和超时。

本项目尚未配置互联网发布服务。该功能检查当前服务器提供的清单，不会自动下载或安装源码。维护者更新文件/部署及清单后，用户可重新载入。浏览器测试中的较新版本与503响应通过测试拦截模拟，不代表真实发布过这些版本。
