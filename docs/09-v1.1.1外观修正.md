# v1.1.1 外观修正

## 版本区

移除“本次更新”、版本发布和版本检查时间。运行中的版本清单只包含版本号和说明，检查结果不保存更新相关时间。检查请求通过禁用缓存获取清单，不再附加时间戳。旧清单带有的额外时间字段会被过滤。

生产模拟时间、订单、告警和维修事件时间不属于版本更新信息，继续保留以支持业务追溯。

## 主题色

原实现的明显变化集中在细线和小图标，部分区域仍使用固定青色。现在导航选中、主按钮、焦点、进度条、排产条、图表主序列和设备选中平台统一响应主题色。外观设置提供即时效果预览，可直接进入驾驶舱查看。

设备运行、故障和维修的状态色保持独立，不随主题色变更。实体模型的材料颜色也继续保留。

## 字号

“系统设置 → 外观与主题 → 界面字号”提供100%、115%、130%、145%四档。缩放实际文字而非整页浏览器缩放，覆盖导航、表格、按钮、说明、三维标签及图表文字。图表留白与高度同时适配，设置跨页面和刷新保留。

原有偏好自动补齐为标准字号。恢复默认设置也会恢复100%，保留订单和维修记录。

## 验证

- 生产构建通过。
- 17项单元用例通过，新增检查结果过滤更新时间字段的验证。
- 13项浏览器用例通过。新增版本区无时间字段、主题色实际按钮与导航样式及图表像素、字号真实尺寸与持久化、最大字号下九页桌面和手机布局检查。
- 主题验证直接读取按钮/排产条绘制结果，并统计图表画布中的主题色像素，避免仅验证状态变量改变。
- 生产构建补充琥珀金浅色主题、字号和移动导航截图，见 `deliverables/screenshots/v1.1.1-*`。

旧版交付包与课程PPT保留，本次运行代码和生产构建以v1.1.1为准。
