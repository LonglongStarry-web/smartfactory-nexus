# P1 机械动作检查点

两单元统一空间锚点；两段机械臂逆运动学；取放、夹爪闭合、开关门、夹具交接、端面/轮廓/钻孔/去毛刺、送检/扫描/分流均读取同一工序状态。5 倍速下 100ms 推进，不再以独立正弦动画模拟生产。运行存档合并到每秒一次，暂停立即保存，页面离开刷新最新快照。

验证：47 项单元测试通过；17 项真实 Chrome 浏览器测试通过；TypeScript 与生产构建通过。新增用例检查两单元全路径可达性、固定连杆长度、工序交接位置连续、夹爪接触，以及渲染场景中 TCP 与工件中心误差小于 0.001 场景单位、暂停位置保持。截图：deliverables/screenshots/v1.2-motion.png。

这是工艺路径的可解释动画，未做碰撞动力学、切屑生成或实际机床轨迹标定。浏览器使用 Windows Chrome / SwiftShader，不能据此声称实机 GPU 帧率。

后续继续内部观察、缺陷追溯、配方换型和物流；最终课程提交版 PPT 将采用最终版证据，并按需求分析、初步设计、原型、评估四部分独立说明。
