# P2 加工观察与历史回放

设备详情的“观察加工”、三维工件点击、质量追溯的“查看加工过程”进入同一观察界面。支持透明外壳、刀路示意、部件说明、实时工序与参数、历史工件选择、时间滑块、跳转工序和 0.25–2 倍回放。

回放读取每件工件保存的配方、参数及已完成工序时间区间；不调用制造时钟、不改库存或订单。未记录逐帧轨迹，停机区间内动作仅按工序区间插值，不能当成精确运动录像。旧存档没有轨迹时不伪造还原。

浏览器验证：内部观察、跳到轮廓加工、播放/暂停、生产状态逐字段保持、390px 无横向溢出、返回车间均通过；无页面异常。截图 deliverables/screenshots/v1.2-observation.png。前一检查点的 47 个单元和 17 个浏览器测试已通过，新增观察流程 1 项通过。
