# 后续核验与评估清单

本清单适用于智造未来 v1.3.0。桌面浏览器测试已记录合成视频流识别及媒体轨道释放结果。下表记录手机实机、用户操作、专家评审、工厂现场和持续运行的后续核验任务。表中结果栏在取得记录后填写。

| 核验项目 | 当前记录 | 需要采集的证据 |
|---|---|---|
| AR 实机记录 | AR 识别成功已确认，设备和量化记录可补录 | Android 和 iOS 的识别成功率、首次识别耗时、跟踪丢失与退出释放记录 |
| 用户操作 | 待开展 | 调度、质量及维护任务的完成情况、用时、错误次数和反馈 |
| 需求与专家评审 | 待开展 | 工厂访谈记录，以及对需求、设计、工艺简化和证据的评审意见 |
| 现场工艺 | 待核验 | 真实工程图、刀路、量具实测、运动约束与原型参数的比对记录 |
| 长期运行与部署 | 待核验 | 持续运行时长、存档容量、目标设备上的资源趋势、多人权限与长期历史存储评估 |
